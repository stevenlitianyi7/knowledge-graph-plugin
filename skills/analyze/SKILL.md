# 情境分析器

用户情境：$ARGUMENTS

## Step 1：检索相关知识

```bash
~/.knowledge-graph/.venv/bin/python3 <PLUGIN_DIR>/lib/kg_lite.py analyze "$ARGUMENTS"
```

（其中 `<PLUGIN_DIR>` 是本插件的安装目录，包含 lib/ 的那个目录。）

## Step 2：深度分析

基于检索到的知识图谱上下文，进行以下分析。**严格只使用检索结果中出现的规律和概念**，不要编造图谱中不存在的知识。

### 2.1 识别核心规律

从检索结果中挑选出**与本情境因果关系最直接的 2-4 条规律**（不是所有相关度高的都适用——要判断因果方向是否匹配）。

对每条规律，解释：
- 这条规律在本情境中**具体如何起作用**（不是复述定义，而是映射到情境的具体要素）
- 它预测了什么

### 2.2 构建因果链

用图谱中的关系网络，构建一条从**根因到可观察结果**的因果链：

```
[根因概念/条件] → 通过[规律X] → 产生[中间现象] → 通过[规律Y] → 导致[当前问题]
```

因果链必须：
- 每一步都有图谱中的规律或关系支撑
- 箭头方向清晰（A导致B，不是A和B有关）
- 如果有多条因果路径，分别列出

### 2.3 风险预警

检查以下系统性风险（如果适用）：
- **事与愿违律**：当前的解决方案是否可能适得其反？
- **系统原型**（目标侵蚀/饮鸩止渴/成长上限/转嫁负担）：是否匹配某个陷阱？
- **逆向选择/道德风险**：是否存在信息不对称导致的选择扭曲？
- **反馈回路**：是否有正反馈在加速恶化，或负反馈被破坏？

### 2.4 行动锚点

基于因果链分析，给出 2-4 个**具体可操作**的行动建议。每个建议必须：
- 明确说明它作用于因果链的**哪个环节**
- 引用支撑它的**具体规律**
- 说明预期效果和可能的副作用

格式：
```
💡 行动N：[具体做什么]
   作用环节：因果链中的 [X→Y] 这一步
   依据规律：[规律名]
   预期效果：...
   注意：...（副作用/前提条件）
```

## Step 3：输出格式

用清晰的中文输出，结构如下：

```
## 情境诊断

### 核心规律
（2-4条，每条1-2句映射到情境）

### 因果链
（用箭头图展示）

### 风险预警
（如适用）

### 行动锚点
（2-4个具体建议）

---
📚 涉及规律来源：[列出来源书籍]
```
